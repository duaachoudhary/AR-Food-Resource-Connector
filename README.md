# AR-Food-Resource-Connector
An app connecting Arkansans to nearby food pantries/resources as well as, providing all information such as, times open, locations, phone numbers, etc.

## Features
- User-friendly interface
- Numerous, clickable pantries
- Fast performance
- Call button directly linked to phone numbers 
-Working back button
